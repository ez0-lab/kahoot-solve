Set up once

About five minutes. Use Safari on your iPhone. Nothing here costs money.

  1. Install UserscriptsA free app that adds the helper to the real game page. It needs iOS 15.1 or newer. Open it once after installing. Get the app
  2. Turn it on in SafariTap the aA or puzzle icon in the address bar, then Manage Extensions, then turn on Userscripts. Tap Userscripts in that menu and choose Always Allow on Every Website.
  3. Add the helperOpen the script, tap the same icon, tap Userscripts and follow the install prompt. Open the script
  4. Get a free AI keyCreate a Groq API key and copy it. A Google key is an optional backup that goes under More options, so read What leaves your phone below before you make one. Neither site should ask for a card. If one does, stop and leave it, because this project spends no money. Get a Groq key Google AI Studio, optional
  5. Paste the keyOpen the game page. The settings open by themselves the first time. Paste the key, tap Done and allow the camera. Open the game page
  6. Stop the camera questionOn the game page, tap the same icon, then Website Settings, then set Camera to Allow. The helper can then come back by itself after a reload. This also lets the game page itself use the camera without asking, so set it back to Ask when you stop using the helper.

Practice without a game

Do this once to find the right distance and zoom.

  • Open the practice slide on a laptop or TV.
  • On the game page, tap the gear, then Test camera and AI.
  • Look at the photo it shows. If you can’t read the answers in it, move closer or raise the zoom.

During a game

  • Before you join, tap the gear, then Check free budget. It costs nothing. A question uses one photo, or two if the first is unclear, and a test uses one too. If fewer photos are left than the game has questions, the last questions get no box.
  • Join with the PIN as usual. You can’t use the Kahoot app for this, only Safari.
  • In the lobby, tap the small camera preview to make it bigger, then use the zoom buttons until the host’s screen fills it.
  • When it says Aim at the screen, frame the host’s screen again and keep the phone still until the answers appear.

Guess nowThe line under it says why. Guess right away: a wrong answer costs nothing, and a blank scores zero too.

  • Free AI used up for today means guess for the rest of the game. A 20-question game takes about a third of Groq’s free daily tokens, so two games a day fit and a third may not.
  • The box never blocks your tap. It can be wrong, so read what it says. In one real game, 2 of the 8 answers the AI rated 90% or higher were wrong, so the box says Likely and never a percent.

No app? Use a bookmark

Works without installing anything, but you tap it each time you open the game page. It needs iOS 14.5 or newer.

  1. Copy the code
  2. Save any page as a bookmarkTap Share, then Add Bookmark, name it Quiz Helper and save.
  3. Swap its addressOpen Bookmarks, tap Edit, tap Quiz Helper, clear the address and paste the code.
  4. Use itOn the game page, open Bookmarks and tap Quiz Helper. Anywhere else it takes you to the game page first, and you tap it again there.

What leaves your phone

  • Photos of the host’s screen go to the AI company whose key you added. Groq says it does not keep inference data by default, though it can keep logs for up to 30 days to check reliability and abuse. Google’s free tier can use them to improve its products, and its reviewers may see them. That may break Kahoot’s rule against using its content to improve an AI model, so leave the Google key empty unless you accept that. Google’s terms also ask you to be 18 or older and not to send personal information, and a question about your friend on that screen counts. Keep people out of the frame.
  • Your key goes only to its own company. It is stored on the game page, where that site’s scripts could read it, so never use a key with billing on it.
  • Your notes are never sent anywhere by the helper. Like the key, they are stored on the game page, where that site’s scripts could read them.
  • Nothing is sent to this site, and it has no tracking.
